# cifar10-cnn-model
Practical CNN project on CIFAR‑10. Covered full CV workflow: data handling, model building, regularization, training, and error visualization. Learned to diagnose overfitting and tune hyperparameters for better generalization.

## Dataset
- Source: CIFAR‑10 by Alex Krizhevsky  
- Link: https://www.cs.toronto.edu/~kriz/cifar.html

## Key Features
- Data: loading, normalization, one‑hot encoding.
- Augmentation: random flips, crops, color jitter.
- Regularization: Dropout + L2.
- Training: Adam optimizer, learning rate scheduling.
- Evaluation: validation accuracy, loss curves, confusion matrix, error visualization.
